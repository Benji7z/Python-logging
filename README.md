# Python-logging

Python-logging, it's a logging module featuring... *logging*, *error handling* __and__ *proper error handling\**    

run `logger.py` directly to get a demo, same goes for `example.py`

### *Why would I use this logger?*
> This is a minimal logging tool you can easily add to your projects to have quick, easy and reliable logging
